# Split Studio

Application macOS qui transforme une vidéo en clips verticaux (moments forts IA, sous-titres, « Partie N », rangement par dossiers, publication TikTok).

## Installation

Télécharge [SplitStudio.zip](https://github.com/jhaillard-creator/splitstudio/raw/main/release/SplitStudio.zip), décompresse, glisse **Split Studio** dans Applications, puis clic droit → Ouvrir.

L’application se met ensuite à jour toute seule à chaque lancement.
